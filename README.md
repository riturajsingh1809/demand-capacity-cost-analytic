# Demand, Capacity & Cost Analytics

*Developed by Ritu Raj Singh*

## Project Overview

This project analyzes demand, available capacity, infrastructure cost, operating cost, utilization, capacity gaps, and projected demand to understand operational performance and capacity requirements.

The project follows a practical Data Analyst workflow using *Excel, Python, and Tableau*.

## Objectives

* Analyze demand and available capacity
* Measure capacity utilization
* Identify capacity shortages and gaps
* Analyze infrastructure and operating costs
* Compare current demand with projected demand
* Identify regional and business-segment patterns
* Build an interactive Tableau dashboard

## Tools & Technologies

* *Excel* – Data cleaning and preparation
* *Python* – Data analysis
* *Pandas & NumPy* – Data processing and calculations
* *Tableau* – Data visualization and dashboard
* *GitHub* – Project documentation and version control

## Data Cleaning

The dataset was cleaned and prepared using *Microsoft Excel*. The cleaning process included checking duplicates, handling missing values, standardizing text values, validating data types, and preparing the dataset for analysis and visualization.

## Analysis Performed

The analysis covered:

* Overall demand and capacity
* Capacity utilization
* Regional performance
* Business segment analysis
* Service type analysis
* Monthly demand and capacity trends
* Capacity shortage analysis
* Projected capacity shortage
* Infrastructure and operating costs
* Cost efficiency
* Current vs projected demand and capacity

## Tableau Dashboard

An interactive Tableau dashboard was created to present:

* Total Demand
* Available Capacity
* Total Cost
* Utilization
* Demand vs Capacity Trend
* Regional Capacity Analysis
* Regional Utilization
* Cost by Region
* Capacity Gap Analysis
* Current vs Projected Demand

## Key Outcome

The project provides a structured view of demand, capacity, cost, and utilization patterns and helps present operational data through an easy-to-understand interactive dashboard.

## Conclusion

This project demonstrates an end-to-end Data Analyst workflow, starting with *Excel-based data cleaning, followed by **Python-based analysis* and *Tableau-based visualization*. It highlights practical skills in data preparation, business analysis, KPI development, and dashboard creation.
